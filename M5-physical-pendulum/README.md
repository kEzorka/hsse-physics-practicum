# M5. Физический маятник

Численная модель составного физического маятника «стержень + шар».
Проект рассчитывает момент инерции тела, моделирует свободные и затухающие
колебания, исследует зависимость периода от амплитуды и проверяет сохранение
энергии.

Подробные выкладки, параметры и результаты находятся в
[отчёте по моделированию](docs/report.md).

## Структура

```text
M5-physical-pendulum/
├── README.md
├── requirements.txt
├── run.ipynb          # численные эксперименты и построение графиков
├── config.py          # выбранные маятник и режим, параметры решателя
├── scenarios/
│   ├── pendulums/     # доступные конструкции маятника
│   └── modes/         # начальные состояния и параметры среды
├── src/
│   ├── shapes.py      # геометрия и момент инерции
│   ├── model.py       # уравнение движения и интегрирование
│   └── theory.py      # аналитические формулы
├── docs/
│   ├── report.md      # полный отчёт
│   └── figures/       # графики экспериментов
└── tests/             # аналитические тесты модели
```

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

Откройте `run.ipynb`, выберите ядро из установленного виртуального окружения
и выполните все ячейки. Notebook рассчитывает характеристики маятника,
сравнивает численную модель с теорией и сохраняет графики в `docs/figures/`.
Начальные состояния свободного и затухающих запусков находятся в
`scenarios/modes/`, а конструкции маятников — в `scenarios/pendulums/`.
