# M2. Бильярд на гладком столе

Численное моделирование упругого столкновения двух бильярдных шаров через
решение уравнения движения с деформируемым контактом.

## Условие

> Смоделируйте столкновение идеально гладкого бильярдного шара с другим шаром.
> Детально смоделируйте упругое столкновение, решая дифференциальное уравнение
> на основе 2-го закона Ньютона, если шар считать деформируемым согласно закону
> Гука `F ~ -Δx` (или закону Герца `F ~ -Δx^(3/2)`). Рассмотрите разные варианты
> столкновений (лобовое, под углом, шары одинаковой или разной массы, покоящиеся
> и движущиеся и т.п.). Сравните результаты с расчётами на основе применения
> законов сохранения энергии и импульса.

## Физические допущения

- **Стол идеально гладкий.** Трения нет ни между шарами, ни о сукно.
- **Внешние силы отсутствуют.** Между столкновениями движение прямолинейное
  и равномерное.
- **Задача плоская.** Положения и скорости — двумерные векторы.
- **Бортов у стола нет.** Моделируется одиночное столкновение двух шаров.

### Границы применимости

Оценки для рабочего набора `config.py`: два одинаковых бакелитовых шара,
R = 28.5 мм, E = 4.0 ГПа, ν = 0.35.

- **Малая деформация.** Закон Герца верен, пока радиус пятна контакта
  a = √(R*·δ) много меньше радиуса шара. При v = 1 м/с a/R ≈ 0.05,
  при v = 2 м/с a/R ≈ 0.07.
- **Упругость без потерь.** Модель считает удар абсолютно упругим. Давление
  в центре пятна контакта при v = 2 м/с около 200 МПа — это порядок прочности
  фенольных пластиков на сжатие, при больших скоростях шар может деформироваться
  необратимо. Реальные шары к тому же теряют часть энергии на внутреннее трение.

### Ограничения расчёта

- **Шары в начальный момент не касаются.** Расчёт идёт до момента
  `t_end = 2 · t_touch`, где `t_touch` — время до касания при равномерном
  движении. За время `t_end − t_touch` после касания шары должны успеть
  провзаимодействовать и разойтись. Поэтому начальный зазор между поверхностями
  должен быть намного больше пути, который шары проходят навстречу друг другу
  за время контакта.
- **Точность на границе контакта.** Сила Герца `F = k·δ^1.5` при δ = 0
  негладкая. Если шаг решателя захватывает момент касания, метод высокого
  порядка (DOP853) теряет точность на этом шаге.

## Структура

```
M2-billiard-smooth-table/
├── README.md          # этот файл
├── requirements.txt   # зависимости
├── config.py          # рабочий набор параметров: шары, закон силы, точность решателя
├── state.py           # класс Ball: положение, скорость, радиус, материал, масса
├── model.py           # физика: уравнения движения, интегрирование
├── analysis.py        # обработка решения: сжатие, энергия, импульс, моменты контакта
├── scenarios/         # сценарии столкновений, каждый файл в формате config.py
├── run.ipynb          # прогоны сценариев, графики, серия лобовых ударов
├── report/
│   └── figures/       # графики, которые сохраняет run.ipynb
└── tests/
    └── test_model.py  # сравнение с аналитическими частными случаями
```

## Установка

```bash
python3 -m venv .venv
```

```bash
source .venv/bin/activate
```

```bash
pip install -r requirements.txt
```

## Запуск

Открыть `run.ipynb` из папки проекта, выбрать ядро из `.venv`
и выполнить все ячейки (Restart Kernel → Run All). Графики сохраняются
в `report/figures/`.

Параметры меняются в двух местах:

- `config.py` и файлы `scenarios/*.py`: шары, материалы, закон силы, точность решателя;
- первая ячейка `run.ipynb`: сценарий и скорости серии лобовых ударов, единицы на графиках.

## Тесты

Из папки проекта:

```bash
pytest -v
```

Тесты сравнивают численный результат с теоретическими решениями для частных
случаев, допускающих аналитический ответ.
